# Cloudflare Auto-Configure — Live on branch `cloudflare-autoconfigure`

This branch contains the full end-to-end Cloudflare migration package.

## Quick start

1. Add secrets: `CLOUDFLARE_API_TOKEN` + `STRIPE_SECRET_KEY`
2. Merge this PR (or run workflows from this branch)
3. Actions → **Full End-to-End Auto Configure (Cloudflare)** → Run workflow
4. Done

See `docs/AUTOCONFIGURE.md` for the full runbook.
